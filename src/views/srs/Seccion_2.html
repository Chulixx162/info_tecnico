2. Descripción General

HuilaTour Conecta – Sistema Inteligente de Gestión Turística Regional

2.1 Perspectivas del Producto

El sistema Huila Tour es un producto de software independiente (standalone) diseñado para ofrecer información turística organizada del departamento del Huila. Su objetivo es facilitar a los turistas el acceso a rutas, destinos, itinerarios y precios de servicios turísticos disponibles en la región. Aunque funcionará de forma autónoma, su arquitectura permitirá en el futuro integrarse con plataformas digitales de promoción turística o sistemas institucionales del sector turismo.


El sistema interactúa con el entorno mediante tres interfaces principales:

  • Interfaz de Usuario: La plataforma estará disponible principalmente en versión web, accesible desde navegadores en computadoras, tablets y dispositivos móviles, permitiendo a los usuarios consultar destinos turísticos, rutas, itinerarios y recomendaciones de viaje.
  • Interfaz de Software: El sistema podrá integrarse con servicios externos como APIs de mapas y geolocalización para mostrar ubicaciones de destinos turísticos y facilitar la visualización de rutas dentro del departamento.
  • Interfaz de Hardware: El sistema funcionará en dispositivos convencionales como computadores personales, tablets y teléfonos inteligentes, sin requerir hardware especializado.
  • Interfaz de Comunicaciones: El sistema utilizará protocolos estándar de internet como HTTP/HTTPS para la comunicación entre el usuario, el servidor y la base de datos, permitiendo la consulta y actualización de información turística en la plataforma.

2.2 Características de los Usuarios

Para el desarrollo del sistema HuilaTour Conecta, se identifican diferentes tipos de usuarios que interactuarán con la plataforma. Cada perfil se describe considerando su nivel de educación, experiencia técnica y habilidades específicas, con el fin de diseñar una interfaz accesible y funcional.

1. Turista

Persona que utiliza la plataforma para consultar destinos, rutas turísticas e información general para planificar su visita en el departamento del Huila. Esta persona deberá registrarse e iniciar sesión para desbloquear todas las funciones disponibles.

  • Educación: Nivel educativo variado (secundaria o superior).
  • Experiencia Técnica: Nivel básico o medio en el uso de internet y aplicaciones web o móviles.
  • Habilidades Específicas: Capacidad para buscar información, comparar opciones de destinos y seguir rutas o itinerarios turísticos.

2. Visitante

Persona que utiliza la plataforma para consultar destinos e información general para planificar su visita en el departamento del Huila. Esta persona no se registra ni inicia sesión. A cambio, no podrá acceder a todas las funciones de la plataforma, solo a las funciones básicas.

  • Educación: Nivel educativo variado (secundaria o superior).
  • Experiencia Técnica: Nivel básico o medio en el uso de internet y aplicaciones web o móviles.
  • Habilidades Específicas: Capacidad para buscar información y comparar opciones de destinos.

3. Prestador de Servicios Turísticos

Incluye hoteles, restaurantes, guías turísticos o emprendimientos que ofrecen servicios relacionados con el turismo.

  • Educación: Nivel educativo medio o técnico, en algunos casos formación en turismo o atención al cliente.
  • Experiencia Técnica: Nivel básico o medio en el uso de plataformas digitales para registrar o actualizar información de servicios.
  • Habilidades Específicas: Gestión de información de servicios turísticos, atención al cliente y actualización de datos dentro de la plataforma.

4. Administrador del Sistema

Usuario responsable de gestionar la información dentro de la plataforma y verificar los registros de prestadores turísticos.

  • Educación: Formación técnica o tecnológica en áreas relacionadas con sistemas, software, administración o turismo.
  • Experiencia Técnica: Nivel medio o alto en el manejo de sistemas informáticos y plataformas web.
  • Habilidades Específicas: Gestión de bases de datos, verificación de información registrada y administración general del sistema.

2.3 Restricciones

El desarrollo y despliegue del sistema están sujetos a las siguientes limitaciones:

  • Normativa Legal: El sistema debe cumplir con la Ley 1581 de 2012, garantizando la protección de los datos personales de los usuarios registrados, especialmente la información relacionada con documentos de identidad y fotografías cargadas en la plataforma.
  • Compatibilidad de Navegadores: La plataforma debe funcionar correctamente en navegadores web modernos como Google Chrome, Mozilla Firefox y Microsoft Edge, asegurando una experiencia estable para la mayoría de los usuarios.
  • Conectividad a Internet: El acceso al sistema depende de la disponibilidad de conexión a internet por parte del usuario, ya que la consulta de rutas, itinerarios y destinos turísticos requiere comunicación con el servidor y la base de datos.
  • Integración con Servicios Externos: Algunas funcionalidades, como la visualización de ubicaciones y rutas turísticas, dependen de servicios de geolocalización externos como Google Maps, lo que implica depender de la disponibilidad y políticas de dichos servicios.
  • Actualización de Información Turística: La precisión de la información sobre destinos, rutas e itinerarios dependerá de la disponibilidad y actualización de datos proporcionados por entidades turísticas y prestadores de servicios del departamento del Huila.

2.4 Suposiciones y dependencias

A diferencia de las restricciones, estas son condiciones que se espera que se cumplan para que el sistema funcione correctamente, pero que no dependen directamente del equipo de desarrollo.

2.4.1 Suposiciones (Assumptions)

  • Se asume que los usuarios cuentan con acceso a internet para consultar la plataforma.
  • Se asume que los usuarios poseen conocimientos básicos para navegar en aplicaciones web.
  • Se asume que los prestadores turísticos proporcionarán información verídica y actualizada sobre sus servicios.
  • Se asume que la información turística del departamento del Huila estará disponible para ser recopilada y organizada en el sistema.

2.4.2 Dependencias (Dependencies)

  • Dependencia de servicios externos de mapas o geolocalización para mostrar ubicaciones y rutas turísticas.
  • Dependencia de servidores o servicios de alojamiento web donde se ejecutará la plataforma.
  • Dependencia de una base de datos para almacenar la información de usuarios, destinos y servicios turísticos.
  • Dependencia de la disponibilidad de conexión a internet para que los usuarios puedan acceder al sistema.
