Metodología de desarrollo de software y gestión ágil del proyecto HuilaTour Conecta.

3. Metodología de Desarrollo

El equipo seleccionó Scrum como metodología para orientar el desarrollo de HuilaTour. Según el documento de metodología realizado, la selección se fundamenta en la necesidad de trabajar de manera flexible, organizada, colaborativa e incremental, permitiendo adaptar el producto a cambios y retroalimentación.

3.1 Justificación de Scrum

Scrum permite trabajar mediante ciclos cortos denominados Sprints. Para HuilaTour, este enfoque facilita la construcción progresiva de módulos relacionados con lugares de interés, recomendaciones, rutas, servicios y eventos culturales. La revisión frecuente del producto permite detectar errores y realizar ajustes antes de que se conviertan en problemas mayores.

También se destaca el carácter colaborativo de Scrum. La distribución de responsabilidades, las reuniones periódicas y la identificación temprana de obstáculos permiten mantener seguimiento sobre las actividades y mejorar continuamente el proceso.

3.2 Roles

Rol Responsabilidad en HuilaTour
Product Owner Representar las necesidades de usuarios e interesados, priorizar funcionalidades y gestionar el Product Backlog.
Scrum Master Facilitar la aplicación de Scrum, apoyar al equipo, gestionar obstáculos y promover la mejora continua.
Equipo de Desarrollo Realizar análisis, diseño, programación, integración, pruebas y documentación necesarias para construir el producto.

3.3 Artefactos

Artefacto Aplicación en HuilaTour
Product Backlog Lista priorizada de requisitos, funcionalidades, mejoras y necesidades del producto.
Sprint Backlog Elementos seleccionados para un Sprint y tareas necesarias para cumplir su objetivo.
Incremento Resultado funcional obtenido al terminar un Sprint y que integra nuevas características del sistema.

3.4 Ceremonias

Ceremonia Finalidad
Sprint Planning Definir el objetivo del Sprint y seleccionar el trabajo prioritario.
Daily Scrum Revisar avance, actividades próximas y obstáculos.
Sprint Review Presentar el incremento y recibir retroalimentación.
Sprint Retrospective Analizar el proceso de trabajo y definir mejoras.
