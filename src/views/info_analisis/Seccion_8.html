Modelo de dominio y modelo conceptual de datos del sistema HuilaTour Conecta.

8. Modelo de Dominio y Modelo Conceptual de Datos

El archivo Diagrama_Dominio_HuilaTour.drawio identifica conceptos y relaciones principales del sistema. Entre las entidades y objetos representados se encuentran Turista, Visitante, Administrador, Proveedor, servicios_turisticos, opiniones, sitio_turistico, categoria, imagen, eventos y Favorito.

8.1 Principales entidades identificadas

Entidad Atributos o información representada
Turista n_documento, tipo_documento, nombre, n_celular, correo, fecha_nacimiento, plan_pago, password, fecha_registro.
Administrador admin/turista, ultimo_acceso, estado y operaciones de administración/consulta.
Proveedor nombre_empresa, NIT, representante, correo, n_celular, direccion, estado, link_redes_sociales.
servicios_turisticos proveedor, nombre, descripcion, estado.
opiniones turista, sitio, calificacion, comentario, fecha.
sitio_turistico proveedor, nombre, descripcion, municipio, clima, horario, precio_ingreso, imagen_principal, estado.
categoria sitio y categoria.
imagen sitio, url_imagen, descripcion.
eventos nombre, descripcion, fecha_inicio, fecha_fin, municipio.
Favorito turista y sitio.
Visitante consulta y visualización de información.

8.2 Relaciones principales

El diagrama representa relaciones de herencia y asociación entre actores y entidades, incluyendo relaciones de contacto, escritura de opiniones, agregación de favoritos, administración, oferta de servicios, pertenencia a categorías y asociación de imágenes con sitios.

El modelo conceptual se encuentra directamente relacionado con los casos de uso porque debe proporcionar los datos necesarios para mostrar destinos, gestionar usuarios, soportar reseñas, administrar proveedores y atender las operaciones del sistema.
